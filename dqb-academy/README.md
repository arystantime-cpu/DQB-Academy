# DQB Academy — прототип

Откройте **index.html** двойным щелчком. Устанавливать программы не требуется. Все иллюстрации и фотографии находятся в assets. Интернет нужен только для шрифта Manrope и внешних ссылок; без него используется системный шрифт.

Для локального серверного просмотра при установленном Node.js: `node server.cjs`, затем http://127.0.0.1:4173. Остановка — Ctrl+C.

## Что работает

- Адаптивная главная страница и мобильная навигация.
- Подбор программы, выбор тарифа, добровольное добавление «Под ключ» и пересчёт суммы.
- Переход в демо-кабинет с выбранной программой. Выбор сохраняется только в браузере; при недоступности хранилища передаётся в адресе страницы без персональных данных.
- Разделы кабинета: обзор, уроки, тесты, практика, документы, оплата. Учебный контент намеренно оставлен пустым.
- FAQ, структура программы, телефоны, email и официальный WhatsApp DQB.
- Навигация с клавиатуры, закрытие диалогов Escape, фокус, подписи элементов, поддержка уменьшенной анимации.

## До запуска

1. Подтвердить статус организации и требования ААК, учебные программы, квалификации преподавателей, порядок аттестации и выдачи документов. Прототип не заявляет одобрение ААК или право выдавать официальные квалификации.
2. Уточнить цены, продолжительность, состав практики, учебную технику, адрес площадки и отдельные экзаменационные расходы.
3. Записать уроки, подготовить и проверить тестовую базу. Официальная экзаменационная база не заявляется.
4. Подключить защищённую авторизацию, серверное хранение, оплату, расписание и выдачу документов. Сейчас нет сервера личных данных, формы регистрации или настоящего заказа.
5. Подготовить публичную оферту, политику конфиденциальности и необходимые согласия. Проверить права на использование брендовых фото перед публикацией.

Сайт не опубликован в интернете. Это демонстрационный макет для обсуждения с руководителем.
