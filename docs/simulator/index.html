Онлайн FPV-симулятор

Задание. Взлети с синего старта, пройди ворота 1 → 2 → 3 и сядь в зелёной зоне.

Карта Field. W/S — газ, A/D — поворот, стрелки — наклон. R — начать заново, Esc — пауза. После запуска кликни по сцене для управления.
